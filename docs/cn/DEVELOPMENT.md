# 借助 AI 修改本项目：开发路线与已知坑

[English](../en/DEVELOPMENT.md) · [AI入口](../../AGENTS.md) · [文档索引](../README.md)

不熟悉安卓开发也可以从已有功能的小改动开始。先让 coding agent 读入口并指出实际代码与测试，再修改。这个仓库已经提供设备通信适配、构建工具、测试及界面源码；无需先学习全部 Android 逆向，更不需先找一套厂商完整 SDK 文档。

## 先认清四层

```text
手机界面与配置（CloudActivity、TodoActivity、WeatherActivity）
        ↓ 用户操作 / 页面状态
会话、录音、助手协调（SdkProbeActivity、ConnectionService及状态类）
        ↓ 有归属与顺序的命令
本项目设备适配 / 厂商通信依赖 → 眼镜固件

云识别、回答、知识库、天气 → 各自客户端 → 上层结果处理
```

手机发完、蓝牙回包、眼镜开始显示、镜片读到最后一页是不同节点；固件可以独立保留数据、处理按钮和熄屏。不要把眼镜当成完全由手机逐帧绘制的屏幕。

| 名词 | 在这里的意思 |
| --- | --- |
| application ID / profile | 安装到手机的包身份 / 构建配置；本版用 sdk-lab。Java源码包名仍可为 dev.xr.rayneo.probe。 |
| 会话 | 一次设备连接与业务状态的归属。换会话后旧回调不能操作新会话。 |
| 回合 | 一次助手收音、识别、回答及显示；不能拿旧回合成功覆盖新回合失败。 |
| ASR / 断句 / 意图 | 语音转文字 / 何时认为说完 / 文字要做什么。三者不是同一个问题；当前任务口令主要是规则匹配。 |
| 协议回执 | 软件收到的确认；不自动等于佩戴者已看到或听到内容。 |
| ADB / run-as | 电脑与授权手机的调试工具 / 读取可调试App私有状态；不是普通用户权限或远程公开服务。 |
| Gateway | 可选知识库服务的兼容客户端契约；仓库不附服务器，也不提供任意远程任务执行。 |

## 按想改的东西找文件

| 想做什么 | 先看 | 怎么验证 |
| --- | --- | --- |
| 改页面排布、文字、入口 | CloudActivity、CompanionShell、ShellNavigation | 页面/导航测试；确认按钮仍调原有动作，别顺手重写连接状态机。 |
| 加一个设备设置 | GlassesSettingWrite、对应RayNeo*Settings、能力清单 | 缺字段/范围拒绝、保留联动字段、载荷格式；获授权后设备写入→读回→观察→恢复。 |
| 改断句或续问 | StreamingAsr、AsrPartialGate、DisplayedAnswerPolicy、SdkProbeActivity | 区分收音截止、识别终稿、答案发送/显示完成、续问窗口、退出；用虚拟时间与迟到事件测试。 |
| 改录音保存或回放 | GlassesRecorder、RecordingAudio、OggOpusWriter、CloudActivity | 状态与文件测试；不能用可播放的短样本推断长录音/断连恢复。 |
| 加待办操作 | TodoStore、TodoGlassesClient、TodoFullSync、VoiceTodoAction | 手机数据、整表同步、设备勾完成和明确语音创建分别测；重复消息不应复制待办。 |
| 查通知为何没到 | NotificationPolicy、NotificationSettingsUi、系统通知权限 | 先看来源App是否真发系统通知，再看过滤、设备发送、镜片观察；标 ongoing、带前台服务标记或 `service` 类别的常驻提示被有意过滤；三者都没有也仍须通过群组摘要、静音和来源选择等筛选，不能断言一定转发；改判据前先取该通知的 flags/category。 |
| 改天气 | PhoneWeather、WeatherPolicy/Sync/Retry、WeatherActivity | 定位/权限、取数、调度、连接就绪与下发分开；不依赖手机天气App。 |
| 接回答模型或知识库 | CloudConfig、CloudClient、KnowledgeClient、GATEWAY文档 | 用模拟服务验证响应、超时、取消、来源；真实Key只放配置，真实服务测试单独说明。 |
| 查连接/后台故障 | ConnectionService、ReconnectPolicy、SessionOwnership、SessionCommandGate | 先核包名、官方进程、真实会话与权限，再核回连；保留失败现场，别先重置设备。 |

具体类的链接与参数在[能力清单](CAPABILITY-MAP.md)。用 `rg` 搜类名/命令名定位；测试通常以对应功能命名，不必一次把全部源码喂给模型。

## 常见误区与有效做法

1. **代码版本对了，工具却连旧包。** 观察台/空闲采样/模型探针已统一默认 sdk-lab；仍要核对 profile、安装版本与会话归属。应用 ID 不是全仓搜索替换项。
2. **官方App“退出页面”后仍占连接。** 正常断开后退出进程；必要时按明确配对流程解除绑定。已做的解绑未清空镜片数据，但不外推后续固件。普通重连不反复解绑，更不默认恢复出厂。
3. **看到电量就宣布连接完成。** 电量/认证可能先到；助手和录音还需要业务就绪及对应通道。
4. **改一个表冠选项覆盖另外两个。** 方向、双击和息屏长按一起发送；读取本轮原值并保留未改字段。设置不是统一JSON模板：有的辅助字段必须null，有的data必须编码成字符串。
5. **数字范围来自代码，就称为官方全范围。** 已观察的UI、代码校验、设备实际接受、佩戴效果分别记录。抬头角度0–70/0–90差异就是现成例子。
6. **用一个计时器处理所有退出。** 识别停顿、无输入超时、传输截止、显示完成、续问窗口和固件息屏是不同事件。长文本不能按发送开始计“读完”；未知末页回执时不能伪造已显示。
7. **取消后旧任务又更新了新页面。** 保留session/round/recording ID，检查晚到回调与重复停止；不能只取消UI动画而留下后续云请求。
8. **知识库有答案就等于检索命中。** result引用与sources检索事件分别处理；未知/未命中如实显示。镜片长答可能缩短，完整结果和来源在手机。
9. **录音停止就等于文件完整。** 保存阶段和录音阶段分开；失败保留可用原始数据与真实状态。Ogg保存、解码播放和转录不是同一操作。
10. **把调试失败当账号失败。** 新装没有预置asr-test.wav；用选择音频入口。电脑llm.local.json不配置手机。模型、Key和服务地址需匹配。
11. **bootstrap完就有全局keytool。** 它只安装固定工具，不改PATH；按构建指南定位工具。APK签名是自己的，换签名覆盖会失败，卸载会清手机数据。
12. **模板重构会更标准。** 本仓用Python构建，不要让Agent擅自“补齐Gradle”或换框架；先在现有构建链完成小范围可验证改动。

## 给 coding agent 的任务写法

例如：“先读AGENTS与开发能力清单，把录音详情里的文字改清楚；保持录音状态机不变，说明改哪些文件、跑哪些已有检查，不安装手机。”

设备能力扩展示例：“先确认当前是否已有显示高度写入适配与真机证据。如果只有只读字段，请报告缺口，不能猜命令；有现成适配再复用，并先准备离线测试。”

让Agent交付四件东西：具体变更、对应证据/测试、仍未验证范围、当前Git状态。避免只收到“已支持”而没有版本和复现办法。

## 维护文档与交付

功能改变时更新README能力表、相关功能/参数页与中英说明。测试记录写实际版本与条件，不重复用旧结论替新行为背书。对外不附私有凭据、原始用户音频/聊天、内部SDK全文、抓包或解包资料；第三方来源与许可保留。修改后的manifest不再代表原始分发，应在新分发准备时核对文件白名单并重新生成，不能覆盖旧版本证据。

已知App旧文案/诊断限制见[排查指南](TROUBLESHOOTING.md)；这些说明不表示问题已经在界面里修复。

部分源码类名、测试名及注释保留历史阶段/审核编号，便于对应现有测试；它们不是需要另外取得的 SDK 或内部文档。修改依据应以当前源码、公开能力清单和测试为准。
