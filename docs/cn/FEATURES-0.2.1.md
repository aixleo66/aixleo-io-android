# 0.2.1 功能与验证边界

[English](../en/FEATURES-0.2.1.md) | [中文索引](README.md)

这是雷鸟 iO 的非官方 Android 研究 App，当前仍以 App 为中心，不提供稳定 AAR。本文把“有实现”和“在特定设备上验证过”分开。测试基线主要是 Strix OS 1.0.4.12 与官方 App 1.0.4 对照；换固件、手机或系统后须重新验证。

| 功能 | 当前做法 | 验证状态与限制 |
| --- | --- | --- |
| 连接 | 保存已配对设备，建立认证会话；支持附近事件和手机启动后的自动恢复尝试 | 单日靠近和重启后回连通过；隔夜与佩戴中稳定性仍有缺口，手机后台策略会影响结果 |
| 助手 | 眼镜麦克风收音，使用自行配置的云端识别及问答服务，把结果送到眼镜；支持短时续问和部分语音任务 | 真实问答与限定的续问链通过；自然语言意图仍主要是规则匹配，不承诺任意指令理解 |
| 录音 | 手机或眼镜原生菜单发起，本地保存 Ogg Opus，可在手机播放；普通录音不自动转录 | 一分钟量级的保存/播放/拖动通过；较长录音、断线、暂停继续和收音方向另列未完成 |
| 待办 | 手机保存待办并与眼镜整表同步；眼镜原生列表勾完成可回传；从眼镜唤醒助手说明确的新增待办口令，可在手机创建后同步回眼镜 | 13 条基线及当轮增删完成、明确语音创建通过；眼镜原生列表直接新增、跨设备冲突、大批量、提醒和云账号同步未闭合 |
| 天气与时间 | 手机定位取天气，就绪和约每15分钟触发下发温度；同步手机时间 | 连接后的温度及限定的调度验证通过；全天后台、定位移动及系统限制仍待复验 |
| 通知 | 从系统通知栏读取用户选中的来源并转发；按标记过滤前台服务常驻通知 | 真实通知需由来源 App 先发到手机通知栏；同一身份原位更新与不同屏幕状态下可见性未全面通过。0.2.1 新增判据为前台服务标记（`FLAG_FOREGROUND_SERVICE`）或 `service` 类别；原有 ongoing、群组摘要及静音筛选仍有效。真机上一条「短信正在运行」仍被转发，其标志位未取到，原因未证；关闭该应用对应的系统通知类别后，用户自测未再出现。其他应用的同类提示未专门测试 |
| 设备设置 | 读取设备状态与配置；亮度、自动息屏、表冠方向和抬头唤醒有受限操作入口 | 限定真机往返不等于全部官方配置可改；高度/距离、勿扰等写入未闭合 |
| 充电盒 | 能观察入盒、开合盖与盒电量相关状态 | 充电中电量是否持续刷新尚未证实 |

“发送成功”只表示 App/通信层完成，不自动证明眼镜屏幕实际显示；涉及镜片体验时以佩戴观察为准。各场景的复测方法见[测试指南](TESTING.md)，源码入口与参数见[开发能力清单](CAPABILITY-MAP.md)。

与早期公开预览相比，0.2.1 的关键变化是录音文件从旧 WAV 流程改为 Ogg Opus、加入手机眼镜待办同步、天气与时间、更多设备设置、自动重连和 0.2.1 的常驻服务通知过滤。0.2.1 对 0.2.0 本身仅是通知规则小修订。官方 App 可见、但这里没有实现的功能见[设备能力参考](DEVICE-CAPABILITIES.md)。
