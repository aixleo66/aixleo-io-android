# 设备能力与配置参考

[English](../en/DEVICE-CAPABILITIES.md) | [中文索引](README.md)

本页是面向使用者的原创功能摘要，不是官方 SDK 文档，也不是底层协议规格。观察来源主要是官方 App 1.0.4 页面与该版本固件下的研究记录。**官方有控件，不表示本 App 已能写入或该能力已真机验证。** 页面上的当前选中值不是出厂默认值。

| 官方界面可见的能力或参数 | 官方可见范围 | 本 App 0.2.1 状态 |
| --- | --- | --- |
| 镜片亮度 | 页面滑块；研究记录中的数值范围为 1–17 | 手动调节有受限真机验证；自动亮度语义另核，不与外部指示灯混淆 |
| 显示高度与距离 | 两个独立滑块 | 有只读状态线索；写入与完整取值未闭合 |
| 抬头唤醒 | 开关、0°–70°角度盘和恢复默认入口 | 角度与开关有受限往返；实际触发幅度受固件影响，不能把数值当作校准精度 |
| 自动息屏 | 5/10/15/25/40/60/120 秒 | 5 秒与 10 秒往返及镜片观察有验证 |
| 息屏旋钮互动 | 开关 | 官方可见；本 App 的取值映射与效果未闭合 |
| 表冠方向、双击、息屏长按 | 方向与预置快捷动作；亮屏长按的系统动作另处理 | 方向反转有镜片对照；并非任意按键重映射，双击和长按动作不全部支持 |
| 头控确认方向 | 开关及点头/摇头确认配置 | 已有部分读写与限定对照；不同固件需复验 |
| 语音助手设置 | 总开关、唤醒、打断、唤醒词、对话语言及官方模型 | 官方云模型与本 App 自行配置的服务不是一回事；多数系统设置未作为自有可写项发布 |
| 勿扰 | 总开关、眼镜端退出、定时开启 | 官方可见；自有写入未闭合 |
| 隐私与指示灯 | 麦克风权限、外部指示灯自动亮度与亮度档位、分析数据选项 | 官方可见；外部指示灯自动亮度不是镜片亮度 |
| 看板组件 | 模式、天气、日历等组件 | 可读线索不等于组件增删可用；自有卡片安装试验未通过 |
| 通知 | 总开关、来电、短信回复、来源列表 | 本 App 有自己的通知来源选择，语义与官方的过滤规则不能直接互换 |
| 录音处理 | 播放、标记、裁剪、分享及分享格式 | 本 App 已有本地录音与部分标记能力；不宣称官方所有后处理动作已实现 |
| 实时字幕与翻译 | 语言、收音方向、保存音频、翻译模式等 | 当前字幕/翻译试验通道失败并已禁用，不作为可用功能展示 |
| 语言与区域 | App 语言、AI 生成语言、日期/时间格式、温度单位、度量衡 | 官方可见；本 App 未完整实现这些独立配置 |

本 App 的待办同步、天气数据源、云端识别与回答是自有实现策略，不能仅因为使用了眼镜显示与输入就称为官方功能。若要为某项开放设置入口，应先分别取得字段、写入、读回和镜片效果的证据。

## 开发者如何使用这份清单

随包代码支持的参数、读取字段、源码入口见[开发能力清单](CAPABILITY-MAP.md)。其中“官方可见范围”是采集页面范围，“代码允许范围”是适配器校验范围，二者不保证一致。例如抬头唤醒官方页面采集为 0–70°，当前代码接受 0–90°；71–90°没有对应的逐档真机证据，不应当作已证能力。

数值来源分别列为页面观察或源码约束；设备验证主要来自 Strix OS 1.0.4.12 等开发记录，不能将所有参数绑定为该固件下已逐档通过。表冠/头控等只有部分值有佩戴验证，其余保留为扩展线索。
