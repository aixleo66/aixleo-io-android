# 变更记录

这里记录功能、修复和使用方式的变化。各版本的测试结果见[测试记录](AUDIT.md)。

## 0.2 系列（源码与 App 版本 0.2.1）

本节对比的是早期 **0.14 公开预览** 与当前 0.2.1 源码；**0.2.1 相比 0.2.0 本身只改了通知过滤**。

- 连接：加入保存设备后的自动重连、附近事件和开机恢复尝试，以及更细的连接就绪与状态检查。
- 录音：眼镜原生菜单发起与设备停止、本地 Ogg Opus 保存、播放和标记记录。早期“每段五分钟/WAV”为旧版描述，不能沿用为现状；长录音、暂停/继续、收音方向与断线续录另有缺口。
- 助手：短时续问、翻页窗口与语音录音/待办动作；云端识别和模型仍由用户配置。意图识别仍主要依赖规则。
- 待办：手机眼镜整表同步、新增、完成、删除和眼镜勾选回传；提醒、跨设备冲突与大批量未全面验证。
- 天气和时间：手机定位取数、连接就绪与周期温度下发、手机校时；后台长期运行仍待复验。
- 设置与状态：部分亮度、自动息屏、表冠方向、抬头唤醒及充电盒状态的读取或限定验证；不等于官方所有配置已实现。
- **0.2.1 唯一新增规则**：忽略带前台服务标记或 `service` 类别的常驻通知提示，避免无价值内容挡在真正消息之前。真机上有一条「正在运行」提示仍被转发（原因未证），见[功能与验证边界](FEATURES-0.2.1.md)。

各能力的实际证据等级见[功能与验证边界](FEATURES-0.2.1.md)，官方可见但本 App 未支持的选项见[设备能力参考](DEVICE-CAPABILITIES.md)。

## 0.14 交互修复源码预览 — 2026-09-12

### 修复

- F1：文件/预置音频和手机备用诊断共用本轮取消对象；取消读取、ASR 或后续问答时不再继续下一阶段。
- F2：断开命令可中断 busy/pending；旧命令等待回调失效，避免覆盖新状态。
- F3：设备主动停止和本地停止共用收尾期限；缺失完成回报时失败退出并保留原始数据，重复停止不延长期限。
- F4：手机显示、自动投递和手动投递共用当前回答，避免发送前一轮缓存。

### 文档与验证

- F5：明确眼镜连接要求 Android 12+ / API 31，安装声明仍为 API 29；没有新增低版本兼容能力。
- D1：提供 `verify_source.py`，按 Git blob 校验提交清单，避免工作区换行转换干扰。
- 首页说明核心流程此前已跑通，细节交互仍在专项测试和持续迭代中。
- 59 项自动测试与构建检查通过；新代码尚未真机专项验收或外部独立复核。详见[验证记录](audits/2026-09-12-0.14.md)。不附 APK，不创建 GitHub Release。
