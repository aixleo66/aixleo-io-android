## 0.14 交互修复源码预览 — 2026-09-12

### 修复

- F1：文件/预置音频和手机备用诊断共用本轮取消对象；取消读取、ASR 或后续问答时不再继续下一阶段。
- F2：断开命令可中断 busy/pending；旧命令等待回调失效，避免覆盖新状态。
- F3：设备主动停止和本地停止共用收尾期限；缺失完成回报时失败退出并保留原始数据，重复停止不延长期限。
- F4：手机显示、自动投递和手动投递共用当前回答，避免发送前一轮缓存。

### 文档与验证

- F5：明确眼镜连接要求 Android 12+ / API 31，安装声明仍为 API 29；没有新增低版本兼容能力。
- D1：提供 `verify_source.py`，按 Git blob 校验提交清单，避免工作区换行转换干扰。
- 首页说明核心流程此前已跑通，细节交互仍在专项测试和持续迭代中。
- 59 项自动测试与构建检查通过；新代码尚未真机专项验收或外部独立复核。详见[验证记录](audits/2026-09-12-0.14.md)。不附 APK，不创建 GitHub Release。
