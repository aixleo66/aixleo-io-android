# 兼容性与验收范围

这里汇总已经测试的设备、系统与功能场景，以及尚待验证的限制。各版本的自动测试和构建结果见[测试记录](AUDIT.md)。

当前 0.2.1 主要依据单台测试手机与单副雷鸟 iO 的开发记录；历史公开矩阵用过小米 MIX Fold 4（24072PX77C）、Android 16 / API 36。通信依赖来自官方 Android App 1.0.2（68），但设备侧功能核对涉及后续官方 App 和固件版本。各场景的具体固件、系统和版本仍需逐条带证据记录；不能据此保证任意固件兼容。

**当前眼镜连接要求 Android 12+ / API 31。** Manifest 中的 minSdk 29 仅是安装声明；连接初始化会明确拒绝 API < 31。API 31～35 的真机覆盖不足，已有主要手机记录来自 API 36。

| 场景 | 0.2.1 可据以说明的范围 |
| --- | --- |
| 自有设备连接、认证、文字通知 | 已有业务回执与用户镜片确认 |
| 眼镜麦克风→实时 ASR→提问文字→回答 | 已有用户确认；无须以手机麦克风替代 |
| 连续问答 | 修复旧轮清理和续问触发后有多轮成功；所有 type11 情形仍不能一概推断 |
| 熄屏语音问答 | 已有用户确认；不是无 USB 深度休眠和所有 ROM 策略的证明 |
| 普通录音、保存、播放 | Ogg Opus 本地保存、回放及一分钟量级片段已有真机记录；长录音、异常恢复与跨设备兼容尚未闭合 |
| 飞书通知 | 手机正常提醒，眼镜显示完整；其他应用及高频场景需分别测试 |
| 空闲调用 | 约定三分钟不操作，19 次采样无新增收音、ASR 或云上传，远端任务数不变；不是整夜功耗结论 |
| 远端知识库 | 完整问答和指定问题来源显示通过；自然语音问句的引用仍不稳定，不能据此认定实验性 Gateway 的可用性和稳定性充分 |

已知问题：偶发连接中断尚未完全定位；通知原位更新未实现；知识库自然问句引用和长答退出时序需继续改进；录音长时、跨设备冲突、全天后台、盒内电量刷新及多手机系统覆盖仍需验证。功能逐项边界见[功能表](FEATURES-0.2.1.md)。

如果你使用其他手机或固件，欢迎通过 Issue 分享版本、设备环境、复现步骤和脱敏结果，帮助扩充兼容性记录。
