# 兼容性与验收范围

这里汇总已经测试的设备、系统与功能场景，以及尚待验证的限制。各版本的自动测试和构建结果见[测试记录](AUDIT.md)。

下表是历史 0.12 功能基线的真机结果：RayNeo iO；小米 MIX Fold 4（24072PX77C）Android 16 / API 36。厂商依赖基线为官方 Android App 1.0.2（68）。眼镜固件版本尚未补入此公共矩阵，不能据此保证任意固件兼容，也不能据此标记后续版本全部通过。

**当前眼镜连接要求 Android 12+ / API 31。** Manifest 中的 minSdk 29 仅是安装声明；连接初始化会明确拒绝 API < 31，因此 Android 10/11 的这条连接路径不支持，并非只是“未实测”。API 31～35 尚未完成对应真机验证；已有历史真机记录来自 API 36。主要验证来自单台手机和单副眼镜，需要更多设备覆盖。

| 场景 | 验收结果 |
| --- | --- |
| 自有设备连接、认证、文字通知 | 已有业务回执与用户镜片确认 |
| 眼镜麦克风→实时 ASR→提问文字→回答 | 已有用户确认；无须以手机麦克风替代 |
| 连续问答 | 修复旧轮清理和续问触发后有多轮成功；所有 type11 情形仍不能一概推断 |
| 熄屏语音问答 | 已有用户确认；不是无 USB 深度休眠和所有 ROM 策略的证明 |
| 普通录音、保存、播放 | 用户短录音确认通过；留存最长一段约 56 秒。五分钟上限及异常恢复尚需专项测试 |
| 飞书通知 | 手机正常提醒，眼镜显示完整；其他应用及高频场景需分别测试 |
| 空闲调用 | 约定三分钟不操作，19 次采样无新增收音、ASR 或云上传，远端任务数不变；不是整夜功耗结论 |
| 远端知识库 | 完整问答和指定问题来源显示通过；自然语音问句的引用仍不稳定 |

已知问题：播放进度条偶发不一致；连续通知堆叠/更新效果未解决，暂保留独立编号；远端取消与本地取消未完全联动；连接仍依赖研究版 Activity 生命周期；长时功耗、入盒/摘戴、进程被杀与重启恢复未完整验收。

如果你使用其他手机或固件，欢迎通过 Issue 分享版本、设备环境、复现步骤和脱敏结果，帮助扩充兼容性记录。
