# 功能测试指南

自行构建并安装 0.2.1 后，按下面的最小场景检查连接、录音、助手、待办、天气和通知。离线测试与构建结果见[审核索引](AUDIT.md)，设备覆盖见[兼容性](COMPATIBILITY.md)；它们不能替代你自己的佩戴观察。分享结果时请记录版本和设备环境，并对个人内容及日志脱敏。

## 前提

先完成[首次配置](BUILDING.md)：退出官方 App 进程，按需进入眼镜配对状态，在本 App 选择已配对眼镜并等会话就绪。录音不需要云服务；助手问答需要自己的识别与模型服务配置。通知需系统授权并在 App 选择来源。不要把解除绑定或恢复出厂设置当作普通重连手段。

涉及云识别或模型的测试可能上传语音与问题并产生费用，只用自己的非敏感样本。若要核查离线文件转写，只选择自己明确授权的测试音频。

| 场景 | 操作 | 通过条件 |
| --- | --- | --- |
| 连接与待命 | 在手机连接已配对眼镜，观察认证、设备状态和助手待命 | 会话真正就绪；蓝灯、电量回报或单次认证成功都不足以单独判定 |
| 本地录音 | 从手机或眼镜菜单录约 20 秒，正常停止后在手机录音列表回放 | 产生可播放的 Ogg Opus 文件，时长合理；录音完成不自动转写 |
| 助手与续问 | 唤醒问简短问题，确认镜片回答；在续问窗口内再问另一个问题 | 两轮的提问和回答分别对应，无旧回调覆盖；观察退出与再次唤醒 |
| 待办 | 手机新增一条测试待办并同步，在眼镜勾完成，再回手机核对 | 两侧状态一致，重复同步不产生重复项 |
| 天气与时间 | 授权位置并连接，观察眼镜温度和时间 | 温度有值且时间与手机一致；只说明本轮成功，不代表全天更新 |
| 通知 | 授予系统通知使用权、选择来源，用来源 App 生成一条真实系统通知 | 手机通知栏先出现，再以镜片观察确认对应消息；发送回调不等于显示 |
| 可选知识库 | 配置自己的专用 Gateway 后提问 | 回答及来源在手机可核对；空来源不能证明曾检索资料 |

## 空闲检查

待命就绪且没有正在进行的录音/问答，约定三分钟不唤醒、不按按钮、不在 App 发起请求。在已配置 ADB 的根目录运行：

```powershell
python idle_check.py --serial "替换为手机序列号" --seconds 180
```

工具采集开始和结束两份快照，对比同一会话的录音请求、音频包、云上传、业务提交、实时云连接累计计数及待命状态。`passed` 表示检查范围内计数未增长。如果会话发生变化或计数增加，需要结合期间的操作和日志排查；主动唤醒后请重新开始空闲检查。

输出保存在 `out/power-tests/`，包含原始状态，分享前请脱敏。此工具检查 App 计数器，不测量蓝牙流量、实际电流、云账单或厂商 SDK 心跳；长期耗电需另行测量。

## 留存方式与已知经验

每项记录：日期、候选版本/哈希、手机型号与系统、固件（未知就写未知）、前提、操作、协议结果、佩戴者观察、是否调用云端、异常及脱敏证据。使用 [观察台](OBSERVER.md) 辅助，但不要把模拟渲染当成真实镜片确认。

已知限制包括偶发连接中断、长答退出时序、知识库引用、通知原位更新和较长录音。连接失败先检查官方 App 是否仍占用会话及本 App 的就绪状态，避免盲目反复解绑。长时后台、跨手机系统和固件行为另做专项；见[功能边界](FEATURES-0.2.1.md)与[排查指南](TROUBLESHOOTING.md)。
