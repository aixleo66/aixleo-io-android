# 权限、数据与诊断

这里说明 App 使用哪些权限、数据保存在什么地方，以及哪些操作会访问外部服务。调试构建与 ADB 访问能力见[安全说明](SECURITY.md)。

| 数据/能力 | 当前用途与去向 |
| --- | --- |
| 蓝牙扫描与连接 | 发现并连接使用者选定的眼镜，接收设备事件、音频和状态，发送显示与控制消息 |
| 手机麦克风 | 仅用于用户主动选择的手机麦克风测试；正常眼镜语音从眼镜收音 |
| 普通眼镜录音 | 原始音频、回执和派生 WAV 保存在手机 App 私有目录；保存不会自动调用云转写 |
| 语音助手音频 | 触发语音轮次后，发送到使用者配置的 ASR；实时模式边收边传，可能在误唤醒时产生调用 |
| 提问与回答 | 有效提问发送到所选模型或远端 Gateway；手机保留最近结果，答案发回眼镜；远端保存策略由所用服务决定 |
| 手机通知 | 系统授予通知使用权后，由本地代码按应用/类别过滤；选中的内容发往眼镜，不送给模型 |
| 服务 Key/Token | 由用户填写；当前用 Android Keystore 配合加密文件存储，不提供维护者共享 Key |
| 调试文件与观察台 | 可能包含问题、回答、通知正文、设备标识和会话事件；不是默认脱敏资料 |

通知读取范围由 Android 通知访问权限决定；“只转发选中的应用”是本项目的处理规则，不意味着系统只会交给 App 那几个应用的通知。

## 用户控制

可在 App 中控制待命、录音、通知转发和服务配置；可在系统设置中撤销相应权限。「取消手机任务」会取消对应输入读取、停止手机诊断采集，并阻止后续转写或问答阶段继续提交。取消不保证撤回已上传的数据或终止远端已经接受的任务；服务商可能已处理部分数据并计费。具体验证范围见[审核记录](AUDIT.md)。

观察台仅绑定电脑本机回环地址，通过 USB 读取 App 状态。网页重绘协议内容，可能显示完整的问题、回答和通知正文；分享页面或日志前请先脱敏。目前没有默认隐藏正文和限时观察功能。

## 问题反馈

优先提交版本、设备/系统型号、操作顺序和去正文的状态/错误信息。不要在公开 Issue 上传录音、聊天内容、完整通知、设备地址、序列号、Key、Token 或含真实服务地址的配置。

目前没有专用的私密漏洞反馈渠道。可以先通过已有的维护者联系方式沟通，或在 Issue 中说明问题类型，不附敏感细节。
