当前源码预览：Android 示例 App 0.13，SEC-01/02 已在本地实现修复，源码独立复核、45 项自动测试与构建检查已通过；尚未完成完整真机回归。本仓库不附 0.12 或 0.13 APK。

下表是历史 0.12 功能基线的真机结果：RayNeo iO；小米 MIX Fold 4（24072PX77C）Android 16 / API 36。厂商依赖基线为官方 Android App 1.0.2（68）。眼镜固件版本尚未补入此公共矩阵，不能据此保证任意固件兼容，也不能据此标记 0.13 全部通过。

示例 manifest 最低 API 为 29，不代表 API 29～35 已全部实测。主要真机验证来自单台手机和单副眼镜，需要更多设备覆盖。
