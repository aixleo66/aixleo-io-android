## 当前支持的能力

下表的“已验证”只指记录中的测试手机、眼镜和固件；“有限验证”表示已有实现及部分真机证据，仍不能推广到所有环境。“可选实验”需要另行配置服务。手机发送成功或读到状态，不自动代表镜片上看到了预期内容。

| 模块 | 目前能做什么 | 验证程度与使用边界 |
| --- | --- | --- |
| 连接与会话 | 选择已配对眼镜，建立认证及业务会话，查看连接、待命与部分设备状态 | **有限验证**：正常连接已跑通；认证、电量回报不单独等于全链路就绪 |
| 自动重连 | 对已保存设备尝试附近回连、手机启动后的恢复和语音待命恢复 | **有限验证**：单日靠近及重启后回连有记录；隔夜、佩戴中稳定性和手机后台策略仍需复验 |
| 眼镜语音问答 | 用眼镜麦克风收音，经用户自行配置的云识别与问答服务生成回答并送到镜片 | **限定场景已验证**：短问答与镜片回答有观察；需要自己的服务账号、网络和设备会话 |
| 续问与多轮 | 回答后在短时窗口内继续提问，并处理翻页期间的窗口计时和新旧轮次隔离 | **限定场景已验证**：多轮链路已跑通；长回答退出、异常时序和语义记忆不能视为全面解决 |
| 语音任务口令 | 通过已定义的口令发起录音、待办等操作 | **有限验证**：仅覆盖明确规则；自然语言意图主要靠规则匹配，不能理解任意交办 |
| 可选知识库问答 | 接入用户自己的 Gateway，显示回答并在手机查看服务端提供的来源 | **可选实验**：指定问题的链路有记录；自然问句引用不稳定，空来源不证明完成检索 |
| 普通录音 | 从手机或眼镜原生菜单开始、停止录音，保存手机本地 Ogg Opus 文件 | **限定场景已验证**：一分钟量级保存通过；长录音和断连恢复未闭合，完成后不自动转写 |
| 录音查看 | 在手机录音列表回放、拖动并查看部分标记记录 | **有限验证**：本地回放和拖动有记录；不包含官方的全部裁剪、分享或暂停/继续能力 |
| 待办同步 | 在手机新增、完成、删除待办并同步到眼镜；眼镜原生列表勾选完成可回传手机；从眼镜唤醒助手说明确的“添加待办”口令，可在手机创建后同步回眼镜 | **限定场景已验证**：13 条基线及当轮增删完成有记录，明确语音创建已真机验证；眼镜原生列表直接新增、提醒、云账号和双侧并发冲突未闭合 |
| 天气与校时 | 用手机定位和网络天气获取温度，连接就绪后及周期调度时下发，并同步手机时间 | **有限验证**：温度和时间的限定往返已观察；全天后台、移动后刷新及系统限权仍需验证 |
| 通知转发 | 经系统授权后选择来源 App，把真实手机系统通知转给眼镜；按标记过滤前台服务常驻通知 | **有限验证**：部分真实通知有镜片确认；来源 App 未发系统通知时无内容可转，同一通知原位更新未实现。0.2.1 新增的常驻提示过滤按系统前台服务标记或 `service` 类别判断；真机上曾有一条「正在运行」提示未被命中、照常转发（原因未证），有用户自测通过关闭对应系统通知类别绕行，操作前须确认不影响真实消息 |
| 电池和充电盒 | 读取眼镜电量及部分入盒、开合盖、盒电量状态 | **有限验证**：状态与数值有回报；充电时盒电量是否持续刷新尚未证实 |
| 镜片亮度 | 调节手动亮度，并读取部分显示设置 | **有限验证**：手动亮度有档位和镜片对照；自动镜片亮度与外部指示灯设置不能混为一谈 |
| 自动息屏 | 读取及设置支持的息屏时长 | **限定场景已验证**：5 秒、10 秒的写入、读回及镜片观察已通过；其他档位和固件需另验 |
| 表冠方向 | 读取和切换旋转方向，让同一方向的转动对应反向菜单移动 | **限定场景已验证**：方向反转有佩戴对照；不代表任意按键可重映射 |
| 抬头唤醒与头控 | 读取和调整部分抬头角度、开关及头控确认方向配置 | **有限验证**：有受限写读及观察；触发幅度不等同精确角度，固件差异需复验 |

官方界面可见但本 App **尚未完整支持**的配置，例如显示高度/距离、勿扰、看板组件、实时字幕和翻译，见[设备能力参考](docs/cn/DEVICE-CAPABILITIES.md)。更细的测试范围见[功能与边界](docs/cn/FEATURES-0.2.1.md)、[兼容性](docs/cn/COMPATIBILITY.md)和[常见问题](docs/cn/TROUBLESHOOTING.md)。

## 自行构建与使用

仓库提供完整 App 源码、固定厂商通信依赖、构建脚本和离线检查，**不附维护者的私钥、云服务密钥、录音或 APK**。按[构建与首次使用](docs/cn/BUILDING.md)准备 Windows x64、JDK、Android SDK 和自己的本地调试签名，再安装到 Android 测试手机。眼镜问答需要你自己的识别与模型服务；天气需要位置与网络；通知需要系统通知使用权。

从官方 App 切换前，请正常断开并退出其进程，避免两个客户端争用同一副眼镜。已做的解绑实测未观察到眼镜数据清空；后续官方 App 或固件版本的行为尚未验证。**解绑不是日常重连步骤**。连接成功后的手机回执不能代替佩戴时的镜片观察。

## 数据、来源和许可

普通录音保存在手机，不会仅因录音完成就上传转写。助手收音会发送给你配置的云识别服务，有效提问会发送给问答服务；天气使用手机定位；通知文字可能显示在镜片与调试观察台。详见[隐私说明](docs/cn/PRIVACY.md)和[安全边界](docs/cn/SECURITY.md)。公开问题反馈请删除设备标识、位置、密钥和个人正文。

项目参考了 [Turbo-IO](https://github.com/Turbo1123/Turbo-IO) 的公开研究与实现，但 Android 适配由本项目独立维护。厂商二进制来自官方 App 1.0.2，来源见[第三方说明](docs/cn/THIRD_PARTY_NOTICES.md)；它不受本项目根许可证重新授权，当前来源记录注明再分发授权尚未核实。原创部分按[许可说明](docs/cn/LICENSING.md)适用 PolyForm Noncommercial 1.0.0。本项目不是厂商正式 SDK。

具体构建和测试范围见[审核记录](docs/cn/audits/2026-09-26-0.2.1.md)；这不等于所有设备场景已验收。
