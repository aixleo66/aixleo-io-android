## 功能与历史验证范围

下列真机结果来自 0.12 基线。0.13 调整了诊断入口与会话管理，需按 [测试步骤](docs/TESTING.md) 重新验证，不能把旧版本的结果直接当作新版本全部通过。

| 功能 | 状态与限制 |
| --- | --- |
| 设备连接 | 自有设备配对、认证、保存设备后重连；打开 App 自动尝试连接和语音待命 |
| 眼镜语音助手 | 眼镜唤醒、眼镜麦克风收音、实时转写逐步上屏、模型回答显示；连续问答与熄屏问答有真机结果 |
| 普通录音 | 手机开始/结束眼镜录音，保存原件及 WAV、手机播放；当前每段五分钟上限，长时边界尚未完整验收 |
| 手机通知 | 用户授权后按应用选择转发，每条通知独立编号；飞书真实通知已验证，其他应用须分别验收 |
| 实验性远端问答 | 仅保留 Android 连接适配，不附 Rokid Harness 服务端；这是连接本地 Codex 的一种探索方式，本版尚未充分验证其可用性与稳定性，更多接入方式仍在探索 |
| 浏览器观察 | USB 读取 App 协议状态并重绘文字；不是镜片截图，也不是完整历史归档 |

雷鸟 iO 在本项目中用作麦克风输入和眼镜显示终端，不具备本项目可用的摄像头或扬声器能力。语音识别和模型回答由配置的外部服务处理，不声称在眼镜上运行大模型。

## 数据与费用

- 普通录音默认保存在手机，不自动上传转写。
- 语音助手在眼镜唤醒并进入收音流程后，将本轮音频发送到配置的 ASR；有效文本再发送给所选问答服务。误唤醒也可能产生调用。
- 待命不维持持续 ASR 上传。已有三分钟无操作采样未见新增录音、转写或模型任务，但不代表零耗电或永不误唤醒。
- 手机通知转发不调用模型；通知正文可能出现在眼镜和诊断预览中。
- 使用者配置自己的 Key 和服务，相关调用按服务商规则计费。本项目不附带共享额度或维护者的服务账户。

详情见 [权限、数据与诊断](docs/PRIVACY.md)。
